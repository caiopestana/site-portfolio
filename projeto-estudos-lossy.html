Lossy

Ano 2026

Sobre

Lossy é uma ferramenta online de estilização de imagens. Com ela, designers e desenvolvedores aplicam efeitos como dithering, halftone, pixel art, mosaico e outros diretamente no browser, sem instalar nada, sem abrir software pesado, sem perder tempo com fluxos que não precisam ser complexos.

O projeto nasceu de uma lacuna real: ferramentas para esses efeitos ou são dispersas demais ou exigem programas robustos para tarefas pontuais. O Lossy resolve isso em menos cliques. Faça o upload, escolha o efeito, exporta. Sem atrito.

O nome vem do conceito técnico de compressão com perda (lossy compression) reapropriado como posicionamento estético. Não é sobre perder qualidade por acidente. É sobre escolher imperfeição com intenção. Esse raciocínio guiou cada decisão do projeto, do naming ao detalhe de interface.

Desenvolvi o projeto inteiro: naming e brand strategy, identidade visual com Space Mono, UI e UX da ferramenta, design da landing page e desenvolvimento front-end com HTML, CSS, JavaScript, React e Tailwind. O slogan Degrade beautifully resume o que a ferramenta defende: imperfeição como decisão, não como erro.

Interface desenhada no Figma, construída com Antigravity + React e hospedada no Lovable.
